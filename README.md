# Country Fail — Мир 2026

Облегчённая стратегия по мотивам Hearts of Iron 4 в браузере: страны 2026 года, плавный фронт, союзы,
творческий режим, глобус с дрейфом материков и игра с другом по сети (PeerJS).

Запуск: откройте `index.html` в браузере (нужен интернет для флагов и игры с другом).
Карта генерируется скриптом `tools/build-map.js` из данных Natural Earth.
